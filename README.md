
# Smart Credit Bank

Système intelligent d'aide à la décision pour l'approbation de crédits bancaires, développé dans le cadre du Projet de Fin d'Études en Génie Logiciel (FST Sidi Bouzid — Université de Kairouan), en partenariat avec ATS Informatique.

## Description

Application web permettant d'automatiser et d'expliquer les décisions d'approbation de crédit bancaire grâce à un pipeline de Machine Learning intégré à une architecture web classique.

## Fonctionnalités

- Prédiction d'approbation de crédit via plusieurs algorithmes de Machine Learning (Logistic Regression, Random Forest, Gradient Boosting, XGBoost, SVM)
- Sélection du modèle le plus performant (Gradient Boosting)
- Explicabilité des décisions du modèle avec **SHAP** (Explainable AI)
- Interface web multilingue (Arabe / Français / Anglais, avec support RTL)
- Trois rôles utilisateurs : Admin, Agent, Client
- Base de données relationnelle pour la gestion des dossiers de crédit

## Stack technique

- **Machine Learning :** Python, Scikit-learn, XGBoost, SHAP, Pandas, NumPy
- **Backend :** Flask (API du module ML), PHP
- **Base de données :** MySQL
- **Frontend :** React.js
- **Méthodologie :** Scrum Agile, UML, Git

## Structure du repo

- `bank-credit.ipynb` — notebook d'entraînement et de comparaison des modèles ML
- `database.py` — script de connexion et gestion de la base de données
- `loan_app_db.sql` — script de création de la base de données

## Auteures

Projet réalisé en binôme par **Eya Rebhi** et **Aya Mansouri**, durant un stage de fin d'études chez ATS Informatique (02/2026 – 05/2026).
